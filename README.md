# Обмен наклейками

Android-приложение для обмена наклейками Panini. Вставляешь сообщение собеседника — приложение показывает,
какие наклейки можно у него взять и какие отдать взамен. Работает без интернета, ничего никуда не отправляет.

Приложение сделано для своей семьи: ребёнок и жена меняются наклейками в чатах, а списки номеров
в сообщениях слишком длинные, чтобы сверять их глазами.

## Готовый APK

Последняя сборка — в разделе [Releases](../../releases). Android 8.0 и новее, около 400 КБ.

Установка на телефон:

1. Перекинуть файл на телефон (кабель, Telegram «Избранное», облако — как удобно).
2. Открыть его в файловом менеджере.
3. Android спросит разрешение устанавливать приложения из этого источника — разрешить.
4. Установить.

APK подписан отладочным ключом — для домашнего использования этого достаточно.
Если позже понадобится обновление, собранное заново, оно поставится поверх только с тем же ключом
(`~/.android/debug.keystore`), иначе придётся удалить старую версию.

## Как устроено

Одна Activity с WebView, весь интерфейс — в `app/src/main/assets`:

| Файл | Что внутри |
| --- | --- |
| `app/src/main/java/ru/stickermatch/MainActivity.java` | WebView и мост в Android: буфер обмена, «Поделиться», хранение списков в SharedPreferences |
| `app/src/main/assets/index.html` | разметка трёх вкладок |
| `app/src/main/assets/app.js` | разбор номеров, сопоставление списков, вся логика |
| `app/src/main/assets/style.css` | оформление, светлая и тёмная темы |

Списки хранятся в SharedPreferences через мост, поэтому не теряются при очистке кэша.

### Разбор номеров

* номера через запятую, точку с запятой, пробел или с новой строки;
* диапазоны `120-130`, `1-200` — любые два числа через тире считаются диапазоном;
* повторы `232(3)`, `16x2` или просто дважды написанный номер — столько же штук (формат со скобками берут из объявлений);
* время, даты, цены и годы (`11:43`, `30.10`, `11 ₽`, `2025-2026`) номерами не считаются;
* раздел определяется по словам: *ищу, нужно, не хватает* → «он ищет»; *в наличии, есть, отдам, дубли* → «у него есть».
  Если в строке есть и то и другое, побеждает слово, которое встретилось раньше.

Если ключевых слов нет совсем, приложение спросит, куда отнести найденные номера.

## Несколько альбомов

У каждого альбома свой набор списков. Альбом выбирается в шапке, управление — на вкладке
«Мои наклейки» (кнопки «Новый», «Переименовать», «Удалить»).

В хранилище: `albums` — JSON вида `[{"id":"a1","name":"РПЛ 2025/26"}]`, `album.current` — выбранный,
а сами списки лежат по ключам `a.<id>.my.have`, `a.<id>.my.need`, `a.<id>.my.owned`, `a.<id>.my.mode`,
`a.<id>.my.size`, `a.<id>.their.have`, `a.<id>.their.need`, `a.<id>.raw`.

Списки, которые велись до появления альбомов (ключи без префикса), при первом запуске переносятся
в альбом «Мой альбом».

## Иконка

Исходник — `art/icon-source.png` (1024×1024). Комплект пересобирается скриптом:

```
python tools/make-icons.py
```

Скрипт срезает поле вокруг плитки, берёт цвет фона с середин её сторон и вписывает картинку
в безопасную зону адаптивной иконки (Android показывает только центральные ⅔ — остальное
срезает маска круга или сквиркла). На выходе: `mipmap-*/ic_launcher_fg.png` (слой адаптивной
иконки), `mipmap-*/ic_launcher.png` (запасной вариант) и цвет `icon_bg` в `values/colors.xml`.

Чтобы поменять иконку, достаточно положить другой PNG в `art/icon-source.png` и прогнать скрипт.

## Сборка

Нужны Android SDK (platform 36, build-tools 36) и JDK 17+. Путь к SDK — в `local.properties`
(`sdk.dir=...`, файл создаётся локально и в репозиторий не попадает).

```
./gradlew assembleRelease
```

Готовый файл — `app/build/outputs/apk/release/app-release.apk`.

Проект открывается в Android Studio как обычно.

## Проверки

```
node tools/parser-test.js    # разбор сообщений на реальных примерах из переписки
node tools/serve.js          # интерфейс в браузере на http://localhost:8777, без пересборки APK
```

В браузере работает всё, кроме кнопок, которым нужен Android: «Вставить из буфера» и «Отправить список».

Для проверки на живом Android есть эмулятор (образ `system-images/android-36/google_apis/x86_64`,
AVD `stickermatch`):

```
"$ANDROID_HOME/emulator/emulator" -avd stickermatch -no-window -no-audio -no-boot-anim
adb install -r "dist/Обмен наклейками.apk"
adb shell am start -n ru.stickermatch/.MainActivity
adb exec-out screencap -p > screen.png
```

Отправить в приложение сообщение, как из мессенджера («Поделиться»):

```
adb shell am start -a android.intent.action.SEND -t text/plain --es android.intent.extra.TEXT "текст" -n ru.stickermatch/.MainActivity
```
